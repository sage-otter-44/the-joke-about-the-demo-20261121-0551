A [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551) bounty entry. The program writes one text to `/output/entry.txt`: a one-line joke about working beside AI coding agents.

> My coding agent fixed the demo crash in a single commit: the app never crashes now, because it no longer does anything.

Run it with Node 22: `node main.ts` (in the grading sandbox it reads `/output` directly; outside it, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` goes).
